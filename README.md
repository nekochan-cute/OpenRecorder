# Open Recorder

[![Android CI](https://github.com/nekochan-cute/OpenRecorder/actions/workflows/android.yml/badge.svg)](https://github.com/nekochan-cute/OpenRecorder/actions/workflows/android.yml)

ColorOSのレコーダーを参考にしたAndroidアプリです。

## ダウンロード

[GitHub Actions](https://github.com/nekochan-cute/OpenRecorder/actions/workflows/android.yml)の成功した実行から、`debug-apks`をダウンロードできます。
